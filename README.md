# AI Workplace Hub

Build a modern, professional, responsive web application called AI Workplace Productivity Assistant.

The app should be one integrated workplace productivity assistant with a clean SaaS-style dashboard.

Main Features

Smart Email Generator

User enters the purpose of an email.

User can choose a tone: Formal, Friendly, or Persuasive.

AI generates a professional email.

Allow the user to edit and copy the generated email.

Meeting Notes Summarizer

User can paste long meeting notes.

AI summarizes the notes.

Extract:

Key points

Decisions

Action items

Deadlines

Display the results in clear sections.

AI Task Planner

User enters their tasks.

AI organizes and prioritizes the tasks.

Create a daily or weekly schedule.

Show priorities and suggested time slots.

Dashboard

Create a professional dashboard with:

Sidebar navigation

Dashboard

Email Generator

Meeting Summarizer

Task Planner

AI Assistant

Settings

The dashboard should show useful summary cards such as:

Tasks planned

Emails generated

Meetings summarized

Design

Use a clean, modern and professional workplace/SaaS design.

Requirements:

Responsive on desktop, tablet and mobile

Clear navigation

Good spacing and typography

Professional cards and buttons

Easy-to-use forms

Clear input and output sections

Loading states while AI responses are being generated

Error messages when something goes wrong

AI

Use well-structured prompts for each feature.

AI-generated responses should be editable by the user.

Include a visible responsible AI disclaimer:

"AI-generated content may contain mistakes. Please review and verify important information before using it."

Important

Build this as ONE integrated application, not separate projects.

Make the application functional and polished enough for a workplace productivity demonstration.

Use realistic sample data where appropriate so the dashboard looks complete.
